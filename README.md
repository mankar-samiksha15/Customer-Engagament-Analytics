# Customer Engagement Analytics

## Project Overview

This project analyzes e-commerce customer interaction data to understand
customer engagement and purchasing behavior.

The objective is to use historical customer interaction data to identify
engagement patterns and develop machine learning approaches for predicting
purchase behavior and recommending products.

## Objectives

- Analyze customer engagement patterns
- Understand product interaction and purchasing behavior
- Create customer-level behavioral features
- Build a machine learning model for purchase behavior
- Develop a product recommendation approach
- Generate insights for targeted marketing and customer retention

## Dataset

The dataset contains customer interaction history including:

- UserID
- EventID
- ProductID
- ProductName
- Quantity
- EventDateTime
- UnitPrice

## Methodology

### 1. Data Cleaning
- Handled missing values
- Cleaned column names
- Converted date/time variables
- Prepared transaction-level data

### 2. Exploratory Data Analysis

Analyzed:

- Customer activity
- Product interactions
- Purchase patterns
- Transaction quantities
- Product preferences

### 3. Feature Engineering

Created customer-level features such as:

- Total interactions
- Unique products interacted with
- Total quantity
- Average product price
- Purchase history

### 4. Machine Learning

A Random Forest classification approach was explored to model
customer purchase behavior.

### 5. Recommendation

Historical customer-product interactions were used to identify
products with higher relevance to individual customers.
